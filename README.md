# Lab notebook · Física I UADE

Calculadora del TP1 (mediciones, propagación de errores y densidad) más un handbook de la clase. SPA en Vite + React, sin backend.

## Mañana en el laboratorio

1. **Si hay red:** abrir la URL de GitHub Pages del repo (`https://<usuario>.github.io/uade-physics-lab/`).
2. **Plan B, notebook:**

```bash
npm install
npm run dev
```

3. Exportar JSON de la sesión (barra lateral) por si el navegador borra datos.

En Pages hay que activar **Settings → Pages → GitHub Actions** la primera vez.

## Qué hace el TP1

- Volumen de tres cuerpos por fórmula (parciales + extremos) y por probeta.
- Densidad $m/V$ y gráfico masa–volumen (incluye (0,0)).
- Al formulario van **derivadas parciales**. Extremos son para comparar.
- Unidades de entrada mm/cm; el informe pide cm y ml.
- Documentación buscable con la teoría de las clases 1–3.
